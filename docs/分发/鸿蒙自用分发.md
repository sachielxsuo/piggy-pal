# 鸿蒙（HarmonyOS NEXT）自用分发 Checklist

> 状态：v1.0（2026-10-20）
> 范围：把 PiggyPal 装到家人鸿蒙手机上的账号、签名、安装流程
> 前提：自用、非商用；走**调试签名 / 内测分发**，不上架应用市场（佩奇 IP 版权，上架必拒）

---

## 一、结论速览

| 问题 | 答案 |
|---|---|
| 要不要开发者账号？ | 要，但**免费个人华为账号**即可，不需企业认证、不花钱 |
| 要不要签名？ | 要，HAP **必须签名**才能装，没有「未签名安装」 |
| 装家人手机难吗？ | 不难：调试签名 + 每台手机登记 UDID + `hdc` 安装 |
| 上架应用市场？ | 走不通（佩奇 IP 版权），自用场景也不需要 |

---

## 二、签名三件套

鸿蒙签名 = 三个文件，缺一不可：

| 文件 | 说明 |
|---|---|
| 密钥库 `.p12` | 开发者私钥 |
| 证书 `.cer` | 华为 CA 签发，绑定开发者身份 |
| Profile `.p7b` | 描述文件：声明包名、签名证书、**允许安装的设备 UDID 列表** |

分两种 Profile：

| 类型 | 是否绑定设备 UDID | 用途 |
|---|---|---|
| **调试签名** | 是，每台设备都要登记 | 自用 / 家人手机侧载 |
| **发布签名** | 上架版不绑；「测试发布」版绑 | 应用市场上架 / 内测分发 |

---

## 三、分发方式对比

| 方式 | 账号门槛 | 是否绑 UDID | 有效期 | 适合 PiggyPal？ |
|---|---|---|---|---|
| **调试签名 + hdc 安装** | 免费个人号 | 是 | 短，需定期重签 | ✅ **推荐**（家人几台够用） |
| **内测分发（AGC）** | 免费个人号 | 是 | 中 | ✅ 备选，体验稍好 |
| 应用市场上架 | 个人/企业 + 软著 | 否 | 长期 | ❌ IP 版权必拒 |

## 四、账号准备

- [ ] 注册华为开发者账号（免费，个人实名认证）
  - 入口：华为开发者联盟 `developer.huawei.com`
- [ ] 下载安装 DevEco Studio（含 OpenHarmony SDK、hdc 工具）
  - 版本要求：见鸿蒙适配版 Flutter 仓库说明（API12 / DevEco 5.0 起步）
- [ ] 配置环境变量：`DEVECO_SDK_HOME`、`ohpm`、`hvigor`、`node`、`JDK17`

---

## 五、推荐路径：调试签名 + 设备安装（分步）

> 前提：鸿蒙版 Flutter 工程已能 `flutter build hap` 成功（工程改造见《技术选型与方案设计》之外的改造评估）。

1. **开启自动签名**
   - [ ] DevEco Studio 里登录华为开发者账号
   - [ ] 工程 → Signing Configs → 勾选「Automatically generate signature」
   - [ ] 生成调试证书 `.cer` + Profile `.p7b` + 密钥库 `.p12`

2. **登记每台家人手机的 UDID**
   - [ ] 家人手机「设置 → 关于本机」连点版本号，开启**开发者模式**
   - [ ] 手机用数据线连电脑，DevEco 自动读取并登记 UDID（或在 AGC 后台手动添加）
   - [ ] 确认每台设备的 UDID 都已进入当前调试 Profile

3. **打包调试 HAP**
   - [ ] `flutter build hap --debug`（或按适配版文档的 `--release` + 调试签名）

4. **安装到每台手机**
   - [ ] 手机开启 USB 调试
   - [ ] 方式一（命令行）：`hdc install <hap 文件路径>`
   - [ ] 方式二（IDE）：`flutter run -d <deviceId>` 或 DevEco 里 Run

5. **验证**
   - [ ] 首次启动会弹「安装来源」风险提示，确认允许
   - [ ] 麦克风权限正常（`ohos.permission.MICROPHONE` 已声明）
   - [ ] 录音 → 后端 ASR → TTS 播放全链路通

---

## 六、备选：内测分发（体验稍好）

- [ ] 在 AppGallery Connect 创建应用，开通「内测分发」
- [ ] 使用「测试发布」签名（同样绑定家人设备 UDID）
- [ ] 把家人加为测试账号，通过邀请链接 / 二维码安装
- 优点：家人后续装新版更省事；缺点：前期配置多一步

---

## 七、针对 PiggyPal 的注意事项

1. **IP 版权**：佩奇（Peppa Pig）是 eOne/Hasbro 版权，上架 AppGallery 必拒。自用分发**不需要上架**，因此也**不需要软著、企业认证、审核**——免费个人号 + 调试签名即可。
2. **调试证书有效期**：到期后需重新签名并重装，DevEco 会自动续证书，但**打包安装动作要重做**。
3. **音频插件**：`record` / `just_audio` 等需鸿蒙化版本，录音 16kHz WAV 与 mp3 播放需在真机实测（这是改造期最大风险点，与本分发流程无关但会影响「验证」一步）。
4. **后端直连**：客户端仍走 `https://piggy.example.com`，鸿蒙真机需能访问该域名（网络环境要通），调试阶段的 whistle 代理在鸿蒙上需改用 `hdc` 相关手段。

---

## 八、需核实项（随华为政策变动）

- [ ] 调试证书当前有效期时长
- [ ] 调试 Profile 的设备 UDID 数量上限
- [ ] 鸿蒙 NEXT 是否允许「从文件管理器直接安装发布签名的 HAP」（政策偏紧，别默认能侧载）
