## 一、产品概述

- **一句话定位**：给自己宝宝（马上满 4 岁）+ 1–2 个朋友宝宝用的 AI 虚拟玩伴英语启蒙 APP。宝宝每天打开，佩奇会喊名字、陪聊天、做小互动、道别并约明天。
- **核心价值**：用"AI 虚拟玩伴"的陪伴感替代"上课感"，让宝宝在无压力、可理解的语言环境里自然"磨耳朵 + 敢开口"。
- **形态**：自用工具，**不上架、不传播、不商用**。

> ⚠️ 版权提示：小猪佩奇（Peppa Pig）是 eOne/Hasbro 的版权形象。**个人家庭自用、不发布、不商用、不传播**属于低风险灰色地带，可放心自己玩；但不要用"佩奇"作为产品名、不要分发、不要商业化。

## 三、角色体系（佩奇家族，现成多角色）

### 3.1 角色阵容

- **主角**：佩奇 Peppa——主持、问候、道别、日常对话。
- **配角**（现成，无需设计）：
  - 乔治 George（弟弟，同龄玩伴）
  - 猪爸爸 Daddy Pig / 猪妈妈 Mummy Pig（家长式角色，安抚/讲道理）
  - 小羊苏西 Suzy Sheep / 小兔瑞贝卡 Rebecca Rabbit（朋友，社交场景）

### 3.2 角色分工

1. 覆盖不同情绪与时段（睡前猪妈妈温柔，白天佩奇活泼）。
2. 宝宝可选想跟谁玩，提升参与感。
3. 陪伴更多元，避免单一角色审美疲劳。

### 3.3 技术实现（简化，无需 Live2D 建模）

- **形象 = 佩奇 PNG 素材 + 简单动效**：用现成佩奇透明底 PNG，说话时做「表情切换 / 缩放 / 口型贴图」即可，不需要 Live2D 建模。
- **角色 = 一份配置对象**：`{ id, 图片, 音色TTS, 人设prompt, 口头禅[] }`。
- **音色隔离**：每个角色绑定独立 TTS 音色，LLM 回复按当前角色选音色。
- **人设 prompt 隔离**：每个角色独立 system prompt，保证性格/语气一致。

## 四、核心功能（MVP）

### 4.1 每日陪伴流程（五步闭环）

1. **问候开场**：喊昵称 + 分时段问候（晨/午/睡前）。
2. **自由对话互动**：佩奇发起轻松话题，宝宝用单词/短句回答，佩奇正向回应（不纠错、不评判）。
3. **星星激励**：完成互动给星星，无失败惩罚。
4. **温柔道别**：到点自动说"今天到这里啦，明天见"。
5. **预告明日**：留钩子（"明天我们去看小动物哦"）。

### 4.2 防沉迷限时

- 默认 10 分钟，可设上限，到点温柔自动收尾。

### 4.3 家长最小页（P0）

- 时长设置 + 简单数据（时长 / 开口次数）。

## 五、页面结构

**宝宝端（3 屏）**
1. 开屏/首页：佩奇大图 + 分时段问候 + 大按钮「开始」
2. 陪伴页：佩奇居中（图片动效），语音对话交互，顶部星星进度条
3. 结束页：道别 + 星星结算 + 预告明日

**家长端（1 屏）**
- 家长中心：时长设置 + 简单数据。

## 六、对话设计

### 6.1 示例（佩奇问候）

> 佩奇（TTS）："安安来啦！我是佩奇，今天想玩什么呀？"
> 宝宝（ASR）："想唱歌"
> 佩奇（LLM + TTS）："好呀！那我们请乔治一起唱吧～"

### 6.2 安全护栏（4 岁对话，必做）

- 内容过滤：拒绝暴力/恐怖/成人/政治等不适内容，回退到"我们聊点开心的吧"。
- 语言边界：句短、词浅、语速慢。
- 情绪正向：永不否定、不施压，所有反馈鼓励式。
- 隐私：自用场景录音本地处理即可，无需上传。

## 7. 技术选型

| 层 | 能力 | 建议 |
|---|---|---|
| 对话 | 大模型 LLM | DeepSeek 官方 API，自由对话 + 角色人设 prompt + 儿童安全护栏 |
| 语音输入 | ASR | 腾讯云实时语音识别（先统一腾讯云跑通）；若 4 岁稚嫩发音识别率不足，再换讯飞儿童 ASR |
| 语音输出 | TTS | 卡通童声音色（腾讯云「云小朵」女童声/「智小虎」童声、讯飞「乐乐」「小桃丸」、火山「小萝莉」「动漫小新」等），每角色一个 voice；或自录卡通童声做声音克隆（9.9 元/角色） |
| 形象 | 佩奇 PNG | 现成素材 + 简单动效，无需 Live2D |
| 客户端 | 原生 APP | 优先 Flutter 跨平台（自用，一台设备跑通即可） |
| 后端 | 编排服务 | 可跑在已有腾讯云服务器（203.0.113.10）或群晖 NAS |
| 持久化 | SQLite | 结构化数据（profile/配置/陪伴记录），单文件零运维 |
| 缓存 | TTS 落盘缓存 + 进程内存 | 固定问候语/口头禅只合成一次；无需 Redis |
| 多用户 | child_id 区分 | 自用 1–2 宝宝，**无登录**；客户端「选宝宝」后请求带 child_id，后端按 id 读写档案 |

### 7.1 架构分层

```
客户端 APP：佩奇图片动效 + 音频采集/播放 + 界面
        │ 流式
对话服务：ASR → LLM(角色prompt+护栏) → TTS
        │
数据层：宝宝 profile / 角色配置 / 陪伴记录（SQLite）
文件层：佩奇图片 / 录音回放 / TTS 音频缓存（本地磁盘）
```

### 7.2 存储与缓存方案（自用版）

**持久化存储**：数据量极小（2 宝宝，每天 1–2 次会话），全部从简。

| 数据类型 | 方案 | 说明 |
|---|---|---|
| 结构化数据（profile、角色配置、陪伴记录） | **SQLite** 单文件 | 零运维零成本，几 MB 级别，够用 |
| 佩奇图片素材 | 服务器本地静态目录 | 几十张 PNG，无需 COS/CDN |
| 录音回放、TTS 音频 | 服务器本地磁盘 | 按文本 hash 命名落盘 |

**缓存方案**（无需 Redis，进程内存 + 落盘足够）：

| 缓存点 | 方案 |
|---|---|
| TTS 音频 | 按文本 hash 落盘缓存，固定问候语/口头禅只合成一次（省 TTS 钱，重启不丢） |
| LLM system prompt | 用厂商侧 prompt cache（固定人设 prompt 自动命中缓存价） |
| 会话上下文 | 进程内存即可（单用户，无并发） |
| 静态图片 | 客户端本地缓存 + HTTP 缓存头 |

**备份**：SQLite 文件 + 文件目录，定时同步到群晖 NAS（用户已有，天然异地备份）。

**升级边界**（当前都不需要）：真正有并发/多实例时再迁 MySQL、上 Redis；素材量大要加速再上 COS+CDN。

### 8.2 月度运维成本（OPEX，按 2 个宝宝估）

用量假设：2 宝宝 × 每天 1 次 10 分钟会话 → 60 次/月。

单次会话 AI 成本 ≈ 0.33 元：
- ASR 0.017 元/分钟 × 5 分钟 ≈ 0.085 元
- TTS 3 元/万字符 × 800 字符 ≈ 0.24 元
- LLM（DeepSeek 2/8 元每百万 token）× 约 7000 token ≈ 0.03 元

| 项 | 月成本 | 说明 |
|---|---|---|
| TTS | ~14 元 | 仍是最大头，但量级极小 |
| ASR | ~5 元 | |
| 大模型 LLM | ~1 元 | 可忽略 |
| 基础设施 | 0 元 | 复用已有资源 |
| **合计** | **≈ 20 元/月** | |

### 8.3 关键结论

1. 自用场景总成本≈**每月 20 元左右**，基本等于白嫖；唯一要花的是"开发时间"。
2. TTS 仍是 AI 里最贵的，但 2 个宝宝一个月才 14 元，无需优化。
3. 如果装 iPhone：一次性 iOS 开发者账号 99 美元/年；装 Android 则 0 成本。
4. 不想花音色钱：直接用 TTS 自带儿童音色（免费额度内），克隆音色是可选加分项。
